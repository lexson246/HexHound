# Security policy

HexHound is experimental. Review findings and generated requests before relying on
them. Use it only against systems you own or are explicitly authorized to assess.
The included vulnerability lab is deliberately insecure and should stay local.

## Reporting a vulnerability in HexHound

Use the repository's **Security → Report a vulnerability** feature when enabled.
If it is unavailable, open an issue asking for a private reporting channel without
including exploit details, credentials, personal data or affected third-party targets.

Include the affected version, a minimal local reproduction, expected and observed
behavior, and the security impact. Redact tokens, cookies and private data from logs.
Do not submit findings about unrelated websites to this project's issue tracker.

Security fixes are developed on the active development branch. There is currently
no guaranteed response time or long-term support policy for older versions.
